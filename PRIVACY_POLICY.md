# Política de Privacidade — mo.co hub

Última atualização: 8 de setembro de 2026.

O mo.co hub é um aplicativo comunitário independente e não oficial.

## Dados armazenados no dispositivo
O aplicativo pode armazenar localmente nome, idade, bio, ID do jogo, imagem de perfil, preferências de tema/idioma, alertas configurados e caches de dados públicos consultados. Esses dados permanecem no dispositivo nesta versão.

## Dados públicos de terceiros
Algumas telas consultam páginas públicas de terceiros para eventos, notícias, rankings e status de jogadores. Ao abrir links externos, passam a valer as políticas do serviço acessado.

## Notificações
O app usa a permissão de notificações para avisos de eventos escolhidos pelo usuário.
